PORTANDROIDRETROID POCKET 5 TARGETPRE-RELEASE

System Shock - Android

The first port developed for the lab, targeting native Android/ARM64 with the Retroid Pocket 5 as the primary reference device.

Playable core port with handheld controls, Android text input, audio integration and a preserved no-stretch 4:3 presentation. Public pre-release v0.1.0-pre.3 includes a signed ARM64 APK and a first-run Android folder importer for the user's own compatible System Shock data. Source, reproduction notes and the engineering knowledge base remain public.

05 / ABOUT

From ports to native games

The goal of this lab is not porting for its own sake. Each port is a practical way to learn a target platform deeply enough to design and build original software for it.

The work is human-directed and AI-assisted. I define the design, process, constraints, creative and critical decisions, hardware interpretation and final acceptance. ChatGPT provides substantial assistance with calculations, programming, automation, analysis, documentation and repetitive technical work.
