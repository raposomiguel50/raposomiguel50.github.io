Coverage policy

Coverage types are kept distinct so an editorial article, a creator's news segment and a community discussion are not presented as equivalent forms of validation.

Mutable platform metrics such as view counts, subscriber counts, likes and reactions are not stored as permanent project metadata. Technical claims, release hashes, compatibility status and validation results remain authoritative only in the relevant project repository and release documentation.
