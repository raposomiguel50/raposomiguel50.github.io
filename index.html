System Shock - Android

An Android/ARM64 port of System Shock, tested on the Retroid Pocket 5.

Version 1.0.0 is available. It includes handheld controls, Android text entry and a first-run importer. Supply compatible game data from your own copy.

NATIVE PORTRG34XX / muOSSOURCE + GUIDES

The Minish Cap - RG34XX

A native port for a GBA-style handheld, built on Project Picori-derived source. The aim is to keep the game familiar while adapting its software to the RG34XX.

Explore the handheld presentation, controls and runtime choices. The learning guide explains their purpose; the technical report links each result to its source.

Integration source and guides are public. A game executable is not available for download.
