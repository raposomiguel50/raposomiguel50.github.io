02 / PLATFORMS

Hardware first

Each platform is treated as its own engineering target. Ports are used to study its constraints, tools, performance characteristics and input model before applying those lessons to native game development.

03 / DEV NOTES

Documenting the process

Development notes will record technical decisions, experiments, performance findings, limitations and reusable lessons from each project.

04 / ABOUT

From ports to native games

The goal of this lab is not porting for its own sake. Each port is a practical way to learn a target platform deeply enough to design and build original software for it.
