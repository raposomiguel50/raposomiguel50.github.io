01 / OVERVIEW

What this public project is

↑ Index

Project Picori foundation

The integration work is based on Project Picori revision e72663ca4059dabf9dbf7f03c36fc791d90b8db5. The complete upstream source tree is not duplicated in the public integration repository.

Hardware-led target

The ANBERNIC RG34XX-H, Allwinner H700 and muOS form the validated reference configuration for the retained private V1.

Public engineering record

The repository publishes integration patches, launcher material, upstream pins, provenance and the documented boundary between public and private project material.

02 / VALIDATION

Verified private V1 identity

↑ Index

SHA-256 evidence

787ba3cb8c297ea44a0605745347fe5a6e792094f0be755b51a8200c1eadc710

This hash identifies the validated private V1 executable retained by the project owner. The executable itself is deliberately not distributed by the public repository.

The exact isolated P13.1 build worktree was not retained, so the public repository does not claim byte-for-byte reproducibility of this binary.

03 / PUBLICATION

A deliberately narrow public boundary

↑ Index

Published

Source patches, launcher/runtime integration material, reference hashes, upstream provenance, licensing notices and development-method documentation.

Not published

No GBA ROM, extracted Nintendo assets, saves, private builds, device backups or validated V1 executable are included.

VirtuaAPU boundary

The private V1 used VirtuaAPU. The audited revision had no explicit published licence file, so its source and the executable incorporating it are not redistributed here.

04 / ENGINEERING

What is preserved publicly

↑ Index

The published repository records the path taken to make Project Picori practical on the H700 target, including accepted work and historical experiments rather than presenting every patch as one linear series.

Architecture

AArch64/H700 build and link work is retained together with upstream pins.

Runtime

Launcher and runtime-policy material documents the RG34XX-H/muOS integration used around the stable private configuration.

History

Timing, presentation, audio, clean-exit and high-refresh investigations remain available as engineering history, including experiments not adopted into the final V1.
