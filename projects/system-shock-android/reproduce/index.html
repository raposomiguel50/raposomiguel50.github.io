1. Get the source

Clone https://github.com/raposomiguel50/system-shock-android.git and check out tag v1.0.0. The build helpers need the clone's Git metadata; a source ZIP is not equivalent.

2. Bootstrap dependencies

Run pwsh -File .\scripts\bootstrap-deps.ps1. The helper obtains SDL and SDL_mixer at the exact pinned commits into the ignored .deps directory.

3. QA build

Run pwsh -File .\scripts\qa-gate.ps1. This builds the isolated QA variant and runs semantic APK verification.

4. Signed build

Independent builders can configure their own release signing environment as documented in docs/RELEASE.md and run pwsh -File .\scripts\release-gate.ps1. Their certificate will naturally differ from the official release identity.

03 / GAME DATA

Bring your own compatible resources

The repository and APK deliberately exclude System Shock commercial resources.

Expected layout

Prepare a legally obtained compatible res folder containing both data and sound.

Public first-run path

Install the stable APK, launch it, choose Select res folder, select the compatible folder and approve access. The importer stages the copy before activation.

Private storage

The imported resources are stored in the application's private Android files area. Keep your original lawful game data separately; uninstalling an app may remove its private storage.

05 / COMPATIBILITY

Independent compatibility reports

Retroid Pocket 5 is the validated reference device. Other Android 13+ ARM64 devices may be compatible, but are only added to the validated matrix after independent testing.
