01 / OVERVIEW

Hardware choice and implemented work

↑ Index

Why this handheld

I grew up mainly with PCs and PC games. The Game Boy Advance was my first console, given to me by my father. I chose the RG34XX for its close physical resemblance to that handheld.

Build integration

The P04 patches change source inclusion, EGL/GLES linking and header order. P06 adds ARMv8-A/SIMD and Cortex-A53 targeting flags. These are build changes, not evidence of original-game glitch repair (Raposo, 2026).

Menu and exit integration

P10.3.2 suppresses the legacy L Settings hint and L-button settings activation in the seamless profile. Its dated verdict records MENU+R2 menu access and MENU+L2 exit checks (Miguel's Game Dev Lab, 2026a).

Presentation scheduling

P11.4 changes the targeted render period from half a logic tick to one logic tick. The resulting trace is measured separately; the policy is not an assertion that every tick has exactly one presentation (Raposo, 2026).

Native target, with runtime layers

The integration targets Linux AArch64 and uses SDL/platform compatibility and audio components. Native CPU execution does not mean bare-metal access or removal of every graphics/audio hardware-model layer.

Source foundation

The recorded Project Picori revision is e72663ca4059dabf9dbf7f03c36fc791d90b8db5. The complete upstream tree is not vendored in this integration repository (Raposo, 2026).

02 / PHILOSOPHY

Approved policy, not a completed-fix list

↑ Index

Technical restoration, preservation and curation define how decisions are made. They do not establish that every intended default or possible correction has been implemented and tested.

Preserve the creative work

Content, art, music, mechanics, progression, deliberate rhythm and original controls remain the reference. New creative content is outside this restoration scope.

Restore, do not repaint

The project's painting-restoration analogy distinguishes the work from a demonstrated technical obstruction. It does not authorize adding detail or inventing an unreleased version of the game.

Investigate before claiming a fix

The policy permits correction of demonstrated original technical bugs. No identified original GBA gameplay-bug correction is substantiated by the current audit.

Curated defaults

The intended reference uses integer 3× presentation, unobstructed gameplay and original GBA controls. Compliance must be checked for each setting; policy approval alone is not runtime evidence.

Efficiency after fidelity

Clock reduction is intended to avoid unnecessary demand while retaining the accepted experience. Measured energy savings are not claimed; the selected records have null energy values.

Transparent differences

Each adopted change should identify its source, reason, test and limitations. Ambiguous behaviour is preserved pending evidence rather than changed merely because an alternative appears preferable.

04 / VALIDATION

Dated observations and limits

↑ Index

30 August: timing captures

P11.3: 10,203 ticks, lateness p95 5.790787 ms. P11.4: 10,449 ticks, p95 0.027887 ms. The maximum presentation-call duration rises from 46.450584 to 60.917250 ms. Outliers remain; these are two archived captures, not a full-game or end-to-end latency result.

5 September: acceptance

The record contains one manual gameplay session with visual/audio OK, two preceding automated soaks and 874 monitor samples. Maximum reported temperature: 52.6 °C. This is not a full-playthrough or all-scenes guarantee.

Clock limits, not energy savings

The final monitor reports CPU maximum 936 MHz and GPU maximum 420 MHz. Stage-A energy eligibility is false and energy values are null. A separate stored P13.1 comparison has a +5.3 °C maximum-temperature delta.

Sources: Miguel's Game Dev Lab (2026a, 2026b). The selected private binary is 8,858,736 bytes, SHA-256 787ba3cb8c297ea44a0605745347fe5a6e792094f0be755b51a8200c1eadc710. Its identity is not a reproducible-build result.

Open documentary findings

The launcher requests 1600 audio frames but prints 1920. The log announces inert save states but records quicksave/autosave writes. The monitor has different pre/post CPU governors despite matching caps and display mode. Two out-of-ROM pointer warnings remain in the accepted session log. These observations are disclosed without assuming their causes or declaring new bugs (Raposo, 2026; Miguel's Game Dev Lab, 2026a, 2026b).

05 / PUBLICATION

Public and private boundaries

↑ Index

Published

Source patches, launcher, reference identifiers, policy, patch inventory, technical report and selected archived evidence. Log excerpts and derived calculations are identified as such.

Not included

No ROM, extracted Nintendo assets, saves or private game executable. The complete raw timing traces are supplied in the audit delivery to the project owner, not in this repository snapshot; hashes do not substitute for public raw-data access.

Dependency restriction retained

The audited publication did not establish redistribution permission for the VirtuaAPU component used by private V1. The affected component and executable remain excluded. This editorial audit does not change their licensing status.
