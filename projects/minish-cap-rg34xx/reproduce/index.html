01 / EVIDENCE LEVELS

Three separate properties

↑ Index

Historical traceability

Versioned patches, source pins and selected archived test records identify parts of the development history. Raw-data access has explicit limits.

Functional reconstruction

A new clean build must run and pass target checks. The September documentation audit did not perform that build or test.

Identical rebuilt bytes

A source/toolchain recipe must reproduce the reference binary hash. That result is not established by the current publication.

04 / STARTING POINT

Inspect before reconstructing

↑ Index

Begin with the recorded upstream revision and patch inventory. Build/link changes, diagnostics, alternative timing policies and historical prototypes have different roles. Do not apply every patch as one sequence or assume that the result matches private V1.

The reconstruction document lists required inputs and checks; it is not presented as an executed, complete recipe.

05 / OPEN GATES

Missing evidence for stronger claims

↑ Index

A complete reconstruction needs exact source ancestry, accepted changes, dependency/toolchain versions, build flags, generated inputs and post-processing. Target checks must cover the resulting artifact, not a previous candidate.

Recalculating archived timing statistics is a different task. Selected summaries, source hashes and reanalysis output are public. The full traces and calculation script are supplied in the audit delivery to the project owner; the full raw files are not included in this repository snapshot. A public hash does not provide the underlying data.

Open findings include audio-buffer diagnostics, save-state/autosave messages, governor restoration and pointer warnings. The audit reports them without silently repairing or dismissing them.

06 / LICENCE

Distribution remains a separate decision

↑ Index

The audited publication did not establish redistribution permission for the VirtuaAPU component used by the private executable. The component and executable remain excluded; this editorial audit does not change that boundary.

No ROM, extracted Nintendo assets or saves are published. Additional package and device claims require their own evidence.
