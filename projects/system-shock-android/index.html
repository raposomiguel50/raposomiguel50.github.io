01 / OVERVIEW

What the stable port is

↑ Index

Source-port foundation

The code foundation is Shockolate, using upstream commit 4cc3d07d…. The Android work is published separately in raposomiguel50/system-shock-android.

Hardware-led validation

The Retroid Pocket 5 is the validated reference device. The accepted baseline covers display behavior, handheld controls, text entry, audio, first-run data import and a complete start-to-finish playthrough.

Commercial data stays external

The source repository and public APK contain no commercial System Shock game data. On first run, users select their own compatible res folder from a legally obtained copy.

04 / PRESERVATION

Stable v1.0 is not a remaster

↑ Index

The product boundary is deliberately conservative. Android-specific adaptations exist to preserve access to the original experience rather than replace it.

Preserved

Original game logic and content remain authoritative. The public presentation stays at 1024x768 4:3 without non-uniform stretching.

Not part of v1.0

No widescreen/Hor+, HD replacement graphics, truecolor conversion, font remaster, replacement music or sound, gameplay rebalance, new maps or new story content.

Android adaptations

Native ARM64 packaging, lifecycle integration, controller mapping, fine cursor input, optional touch pointer, Android text entry, audio platform fixes, first-run data import and release/reproducibility tooling.

05 / INSTALL

No ADB required for normal users

↑ Index
  1. Download and install the signed v1.0.0 APK.
  2. Make your legally obtained compatible System Shock res folder available on the Android device.
  3. Launch System Shock - Android.
  4. Choose Select res folder.
  5. Select the folder containing both data and sound.
  6. Approve access; the importer copies the required files into private app storage and launches the game.

The historical pre-release used package com.rp5np.systemshock. Stable v1 uses io.github.raposomiguel50.systemshock, so both may coexist and maintain separate app-private storage.
